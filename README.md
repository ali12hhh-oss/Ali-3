# Virexalo

Original Android video editor foundation. The project is intentionally independent from LibreCuts and starts with its own package, resources, media model and editor flow.

## Current foundation
- New project opens Android media picker before entering the editor.
- Safe video/image URI handoff into the editor.
- Media3 ExoPlayer preview.
- Play/pause and timeline playhead.
- Editor tool strip: trim, split, text, audio, filters and effects.
- Media3 Transformer export foundation.
- Arabic RTL and English LTR resources.
- No GPL FFmpeg dependency.

The editor is being built as a real editing architecture, following the agreed reference concept without pre-created empty media tracks.
